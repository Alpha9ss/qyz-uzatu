ҚЫЗ ҰЗАТУ ШАҚЫРУ САЙТЫ

1) index.html файлын браузерде ашып көріңіз.
2) Суреттер:
   - Басты фото: assets/photos/cover.jpg
   - Галерея: assets/photos/photo-1.jpg ... photo-6.jpg
   Қосымша суреттер керек болса, index.html ішіндегі gallery бөлімін көшіріп көбейтуге болады.
3) Музыка:
   - Өз MP3 файлыңызды assets/music/music.mp3 деген атпен салыңыз.
   - Музыка браузерде қонақ батырманы басқаннан кейін қосылады.
4) Нақты күн/уақыт:
   - index.html ішіндегі EVENT_DATE мәнін өзгертіңіз.
   - Формат: 2026-12-12T17:00:00
5) Карта:
   - MAP_URL мәніне Sky Palace Google Maps сілтемесін қойыңыз.
6) RSVP:
   - RSVP_WHATSAPP мәніне ұйымдастырушының нөмірін ел кодымен, + белгісінсіз енгізіңіз.
   - Мысалы: 97699123456

Қазір нақты күн/уақыт, карта сілтемесі, WhatsApp нөмірі және жеке фотолар/музыка берілмегендіктен,
оларды кейін оңай ауыстыруға болатын орындар қалдырылды.
